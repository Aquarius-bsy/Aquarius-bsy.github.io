Hello, world — 从这一页开始

2026-08-24 · aquar

个人主页不一定要一开始就很宏大。这一版的目标很具体：有一个能打开的地址，能说清我是谁、在做什么，并且改起来不劝退。

为什么先用三件套

HTML 管结构，CSS 管外观，JS 只处理导航高亮、文章列表和一行打字机效果。没有打包器，也没有框架生命周期。本地用 Python 起一个静态服务器就能预览。

目录也按以后升级来分：

  • css/ 颜色和组件分开，换主题色只动 tokens.css
  • js/posts.js 集中放文章元数据
  • 页面是普通 HTML，之后用 Vite 接入时不必重写内容

接下来可以写什么

适合这个站点的内容，大概是「做过、读过、想清楚了一点」的记录，例如：

  1. 一门课里真正卡住又想明白的地方
  2. 一个小项目为什么这样拆文件
  3. 读 Alignment / 可解释性论文时的疑问，而不是复述摘要

加一篇新文章

复制这个文件，改标题和正文，然后在 js/posts.js 里加一条：

{
  id: "another-note",
  href: "another-note.html",
  title: "另一篇笔记",
  date: "2026-09-01",
  summary: "一句话摘要，会出现在首页和博客列表里。"
}

列表页和首页会自动读到它。不必改构建配置——因为现在还没有构建。
